# 실적 추이 보고

> 에이전트: 영업실적 분석 에이전트 (노현석) · 상태: **작성됨** · 코드: `dashboard/js/sales/rules.js` 의 `trend` · `reportText`

## 언제 쓰나
집계(1번)와 방문 목록(2번)이 끝난 뒤. 본사 월간 보고에 넣을 표와 문장을 새로 쓰지 않고 가져다 쓰게 한다.

## 입력
읽은 건 전체(엑셀에 든 모든 달)와 이번 달 집계 결과, 방문 목록. 달이 하나뿐이면 추이 표는 한 줄이고 비교 칸은 `-` 이다.

## 하는 일 (순서대로)
1. **월별 추이 표**: 엑셀의 달마다 수출 · 수입 · 합계 TEU, 바로 앞 달 대비 증감 · 증감률, 신규 · 이탈 화주 수를 구한다(앞 달과 같은 규칙으로 비교). 수출·수입 비중 막대를 붙인다.
2. **보고 문장**: 이번 달 집계에서 숫자를 그대로 옮겨 쓴다. 새로 계산하지 않는다.
   - 제목 「평택사무소 2026년 10월 영업실적 (전월 2026년 9월 대비) — 단위 TEU」
   - 수출 · 수입 각각: 합계 · 전월 · 증감(률) / 주요 도착지(선적지) 상위 3 / 늘어난 · 줄어든 화주, 신규, 이탈
   - 합계 한 줄, 방문 우선 건수 한 줄(이탈 · 큰 폭 감소 · 신규 · 줄어든 항로)
3. 전월 자료가 없으면 비교 문구를 빼고 「전월 자료 없음」 으로 쓴다.

## 출력
- 화면 「월별 추이」 탭: 추이 표 + 문장(복사 버튼). **보내기는 없다** — 화면 글만 만들고 붙여 넣기는 사람이 한다.
- 결과 파일에는 문장을 넣지 않는다(홈 카드에는 `headline` 한 줄만 올라간다).
- 가상 샘플의 기대 결과: 2026-09 수출 220 · 수입 162 · 합계 382 → 2026-10 수출 241 · 수입 158 · 합계 399(+17, +4.5%, 신규 2 · 이탈 2).

## 확인 필요로 넘길 때
- 달이 3개월 미만 → 추이가 아직 짧다는 안내를 붙인다(맞다고 처리하지 않고 알린다).
- 문장은 초안이다. 고쳐 쓰고 보내는 것은 사람이 한다.
- 문장의 화주·항구 이름은 화면 안에서만 쓰고, 결과 파일·AI 에는 코드(H01 · D01 · O01)만 넘긴다.
