# 서류 점검

> 에이전트: 스페셜화물 승인 보조 에이전트 (kim jaehyung) · 상태: **작성됨** · 코드: `dashboard/js/approval/rules.js` 의 `cleanRequests` · `checkRequest` · `checkAll`

## 언제 쓰나
스페셜화물(DG · OOG · Flexibag) 승인 요청을 받으면 항상 첫 단계. 회신 초안을 쓰기 전에 첨부 서류가 규정에 맞는지 먼저 본다. 병목의 ⭐ 최우선 지점(첨부를 하나씩 열어 확인)을 이 스킬이 맡는다.

## 입력
요청 목록(`data/in/special-cargo-approval/requests.json` 꼴)과 점검 표 4개(필수 서류표 · 숫자표 · CAS 금지 목록 · IMDG 표)·금지 목록(VER.10/11). 요청에 `id · type(DG/OOG/FLEXIBAG) · vessel · pod · origin · docs` 중 하나라도 없으면 그 행은 버리고 「건너뛴 행 N개」로만 알린다.
CAS 목록·IMDG 표는 없어도 점검은 계속하며, 그 단계만 「직접 확인」이 된다.

## 하는 일 (순서대로)
1. **필수 서류**: 요청 유형의 필수 서류표와 비교해 안 온 서류를 `서류 누락` 으로 적는다.
2. **서류 간 대조**: 둘 이상의 서류에 적힌 칸(UN · Class · PG · 중량 · 초과 높이/폭/길이 · 컨테이너)은 표기를 통일한 뒤(UN1307 = 1307, 18,000 KGS = 18000 kg, 1 m = 100 cm) 값이 같은지 본다. 다르면 `서류 불일치`, 읽지 못하면 `직접 확인`.
3. **규정 단계** (유형별):
   - **DG** — STEP 0 금지 목록(발신처가 SKR·흥아 계열이면 VER.11, 아니면 VER.10; 걸리면 규정 위반, 조건부 품목은 직접 확인) → STEP 0.5 IMDG 표의 Class·PG 와 대조(다르면 **직접 확인**, 자동 거절하지 않음) → STEP 1 양하·경유 항구가 상해·닝보이면 MSDS 의 CAS 가 그 항구 금지 목록에 있는지(있으면 규정 위반) → STEP 2 양하·경유가 상해이면 MSDS 농도가 기준(100%)과 같은지(다르면 직접 확인).
   - **OOG** — 초과 높이·폭·길이와 중량이 선박 한도(선박별 표가 있으면 그 값, 없으면 기본)를 넘는지. 서류에 적힌 값 중 가장 큰 값으로 잰다. 넘으면 규정 위반.
   - **Flexibag** — 화물 종류가 허용(NON-DG)인지, 충전량이 한도 이하인지(위반은 규정 위반). COA 연도에 맞는 양식인지(연도 표에 없는 연도는 직접 확인, 양식이 다르면 서류 불일치).
4. 확인 사항을 모아 요청의 판정을 정한다: 규정 위반이 있으면 **불가**, 아니면 하나라도 있으면 **확인 필요**, 없으면 **가능**. 초안 종류도 정한다(불가 → 거절 · 직접 확인이 있으면 초안 없음 · 누락/불일치만 있으면 보완 요청 · 가능 → 승인).

## 출력
- 요청별: `status`(ok/hold/bad) · `draft`(approve/reject/supplement/none) · 필수 서류 체크리스트 · 서류 간 대조 표 · 단계별 결과 · 확인 사항 목록(한글 + 회신용 영문).
- `data/out/special-cargo-docs.json` 의 `table`(요청별 행) · `review`(가능이 아닌 요청마다 한 줄) · `metrics`(점검 건수 · 서류 누락 · 서류 불일치 · 규정 위반 · 직접 확인).
- 가상 샘플 11건의 기대 결과: 가능 3(Q01 · Q04 · Q09) · 확인 필요 5(Q02 누락 · Q03 불일치 · Q07 IMDG 다름 · Q08 상해 농도 · Q11 COA 양식) · 불가 3(Q05 금지 UN 1089 · Q06 상해 CAS · Q10 OOG 높이 한도).

## 확인 필요로 넘길 때
맞다고 처리하지 않고 `review` 에 넣는다.
- UN · Class · 중량 · 치수 · CAS · 농도 · COA 연도를 읽지 못함 → 「… 를 읽지 못함」
- IMDG 표와 Class · PG 가 다름 / IMDG 표에 UN 이 없음 → 「IMDG 와 다름 … 자동 거절하지 않음」
- 금지 목록의 조건부 품목(ISO 탱크만 등) → 「금지 목록 조건 확인 필요」
- 상해 양하/경유인데 MSDS 가 없거나 농도가 기준과 다름 → 「MSDS 농도 85% (기준 100%)」
- IMDG 표·CAS 목록 자료가 없음 → 그 단계를 직접 확인으로
`review` 의 `detail` 에는 선박·컨테이너·화주 이름을 쓰지 않고 코드(Q01 · S01)와 UN · Class 숫자만 쓴다.
