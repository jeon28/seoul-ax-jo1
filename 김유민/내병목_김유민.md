## 2. 한 쪽 정리

### 병목
위험물 확인 단계에서 **컨테이너마다 CERTI(화주)와 SPECIAL LIST(부킹 담당자)의 중량 · PKG · CLASS · UN NO.를 눈으로 하나씩 대조**하는 일.
위험물 선적 건이 있을 때만 발생하며, 한 번에 확인하는 위험물 컨테이너는 1~10대로 매번 다름. 주 3회 × 회당 약 5분 (월 약 1.1시간). ※ 원본 프롬프트의 "10분"을 이후 5분으로 정정함. 시간보다 **한 번 놓치면 선적이 안 될 수 있다는 위험**이 더 큼. → 병목을 정확히 짚었음.

### Input → Output
- **Input:** CERTI PDF 여러 개(1개에 컨테이너 1~N대) + SPECIAL LIST PDF 1개 (모두 텍스트 PDF)
- **Output (화면 요약):**
  `전체 12대 중 2대 불일치 — ABCU1234567: 중량 CERTI 18,200kg / LIST 18,000kg`
  - 짝이 없는 컨테이너(LIST에만 있음 / CERTI에만 있음)도 함께 표시
  - **최종 확인과 정정 요청은 사람이 직접** 함

### 내가 만들 에이전트 1개
**위험물 대조 에이전트** — 정해둔 폴더(또는 Claude 대화)에 PDF를 넣으면 추출 → 컨테이너별 대조 → 다른 점만 요약.
시작은 Claude 채팅에서 스킬로 써 보면서 규칙을 다듬고, 안정되면 Claude Code 폴더 방식으로 옮김.

### 스킬 3개
| 스킬 | 하는 일 |
|---|---|
| ① PDF 추출 | 모든 CERTI와 LIST에서 컨테이너 번호 · 중량 · PKG · CLASS · UN NO.를 뽑아 같은 양식의 표로 만듦. CERTI 하나에 컨테이너가 여러 대면 컨테이너별로 나눔 |
| ② 대조 규칙 | 컨테이너 번호로 짝을 맞추고, 같은 값의 다른 표기를 통일한 뒤 판정함. 예: `UN1263`/`1263`, `3`/`3.0`, `18,000`/`18000 KGS`, `DR`/`DRUMS`. 판정은 일치 · 불일치 · 짝 없음 중 하나 |
| ③ 화면 요약 | 다른 것만 짧게 보여줌. 컨테이너 번호 / 항목 / CERTI 값 / LIST 값 / 원본 쪽수 |

추천 규칙: CERTI에 여러 컨테이너의 **중량이 합계로만** 적혀 있으면 LIST 값을 더해서 비교하고, 결과에 "합계 비교"라고 따로 표시함. 확실하지 않은 값은 일치로 처리하지 않고 **"확인 필요"**로 분류함.

### 조 대시보드에 보탤 결과
- 회차별 대조한 컨테이너 수 / 불일치 건수 / 불일치 유형(중량 · PKG · CLASS · UN NO. · 짝 없음)
- 절감 시간: 회당 5분 → 요약 검토 약 1~2분 (추정치, 시범 운영 후 실제 측정)
- 회차별 기록: 위험물 대수 · 걸린 시간 · 불일치 건수 → 대수가 많을수록 효과가 커지는지 확인
- 다른 조원도 쓸 수 있는 패턴: **"문서 두 개를 기준값으로 대조하는 스킬"**

### 다른 지점 자동화 아이디어 (우선순위 낮음)
- **수출입 마감:** 마감 체크리스트 스킬. 선적 건별로 필요한 서류가 다 들어왔는지(CERTI 포함) 확인하고 빠진 것을 요약함
- **미반입 확인:** 반입 목록과 부킹 목록을 대조해 미반입 컨테이너를 뽑음. ② 대조 규칙 스킬을 그대로 다시 씀
